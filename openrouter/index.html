What OpenRouter is
Think of a food delivery app: one order brings you salad from one restaurant and pasta from another. OpenRouter works the same way for AI. One account and one API key give you models from many providers: OpenAI, Anthropic, Google, DeepSeek, Qwen and others.
TermWhat it means
CreditsPrepaid balance in US dollars. Paid models take from it with every request, free models don’t.
API keyThe secret your agent uses to call models on your account
TokenA small piece of text. Models read and write in tokens, and prices are per million tokens.
Input and outputInput is what you send to the model, output is its reply. They are priced separately.
ContextHow much text the model can take in at once, counted in tokens
Model IDThe exact model name, for example deepseek/deepseek-v4.1-flash
Fallback modelA backup model your agent switches to when the main one stops working
💡
Why you need a fallback. Your main agent runs on your ChatGPT subscription. If a payment fails or the subscription ends, the agent and the course bots stop answering. With a fallback model, OpenClaw switches to it on its own and your agents keep working until you renew.
01
Create an account and protect it
Sign up at openrouter.ai. You can use your Google account. Then turn on two-factor authentication in your account settings: your credits and keys live in this account, so treat it like a bank login.
Account created
Two-factor authentication is on
02
Add credits
Open Settings → Credits and add $15–20. That is enough for a cheap fallback model, and it also raises your limits on free models.
Credits bought in totalFree models allow
Less than $1050 requests a day, 20 a minute
$10 or more1,000 requests a day, 20 a minute
The limit depends on how much you have bought over time, not on your current balance. Source: OpenRouter rate limits.
⚠️
Check the price before you pick a model. A budget model costs cents per million tokens. The most expensive ones cost $120–180 per million output tokens and can empty a $20 balance fast.
🚨
Don’t let the balance go below zero. With a negative balance you may get errors even on free models. Adding credits fixes it.
$15–20 in credits added
03
Create an API key
Open openrouter.ai/keys and create a key. Name it after where it will live, for example “OpenClaw server”, and set a credit limit, for example $10. OpenRouter recommends a limit on every key: if the key leaks, nobody can spend more than that.
💡
You need a regular API key. The separate “Management keys” page is for managing keys from code. Those keys can’t call models, so your agent can’t use them.
🚨
The key is a secret. Don’t paste it into chats, screenshots or documents, and that includes the Claude Code chat. In step 05 you type it straight into the server.
API key created with a credit limit
04
Pick a fallback model
How to look for a model:
StepWhat you do
1. Open the catalogGo to openrouter.ai/models
2. FilterIn the filters on the left, set the context size you need and choose free or paid
3. SortSort by release date to see the newest models first
4. Open a modelIts page shows the price, uptime, meaning how reliably it’s available, and benchmarks, meaning scores on comparison tests
5. Compare and tryCompare puts two models side by side. You can also try a model in a chat on the site before you choose it.
OptionWhen to choose it
DeepSeek V4.1 FlashOur pick for a fallback. Cheap, takes up to about 1 million tokens of context and can use tools, so your agents keep working with them. About $0.05 for input and $0.57 for output per million tokens. ID: deepseek/deepseek-v4.1-flash
Free modelsTheir IDs end in :free. They cost nothing but have the daily limits from step 02, and the list changes often.
Auto RouterID openrouter/auto. OpenRouter picks a model for each request. No extra fee, you pay the chosen model’s price.
Example from the lesson. We compared DeepSeek V4.1 Flash with a Qwen Max model. Qwen also understands video, but it cost about 12 times more. Choose a model that fits your agents’ tasks. On the lesson, DeepSeek was recommended as a low-cost fallback.
Prices on 9 November 2026: DeepSeek V4.1 Flash, Auto Router. Not sure which model fits? Give Claude Code the link to the OpenRouter docs, describe your task and ask it to compare models by price, speed and quality.

05
Connect it to OpenClaw as a fallback
Paste the prompt into Claude Code on your computer. It checks your server and adds the model to the fallback list. Your ChatGPT subscription stays the main model. You type the key yourself in a terminal on the server, so it never goes into the chat. How it works: OpenClaw and OpenRouter, model failover.
Prompt · OpenRouter fallback for my agents
Connect OpenRouter to OpenClaw on my server as a fallback model for my agents. Use the openclaw-docs skill; don't invent commands or config keys. Show me the plan and wait for my OK. Never ask me to paste my OpenRouter API key into this chat, and never print it. Goal: my main model stays my ChatGPT subscription. If it stops working, my agents switch to the OpenRouter model I chose. 1. Ask me for the model ID I chose on OpenRouter. If I have no preference, suggest deepseek/deepseek-v4.1-flash. Find the matching OpenClaw model ref in the docs before adding it: regular models look like openrouter/deepseek/deepseek-v4.1-flash, the Auto Router is openrouter/auto. 2. ssh to my server. Show openclaw models status and openclaw models fallbacks list. Tell me my current primary model. 3. Don't run openclaw onboard or anything else that changes my primary model or replaces my settings. If the docs don't confirm a safe way, stop and tell me. 4. Tell me to open my own terminal, ssh to the server and run: openclaw models auth paste-api-key --provider openrouter. I'll paste the key at its hidden prompt. Wait until I say it's done. 5. Add the fallback: openclaw models fallbacks add <the OpenClaw model ref from step 1> 6. Check each of my agents: an agent with its own model.fallbacks, or fallbacks: [], ignores the default list. Tell me which agents are like that and ask before changing them. 7. Don't run openclaw models scan with probing: it replaces the whole fallback list. 8. Prove the result. Show me a table "check / result / proof": the primary model is unchanged, the fallback list contains my model, openclaw models status --probe --probe-provider openrouter makes a real request and returns ok, openclaw gateway status is OK.
