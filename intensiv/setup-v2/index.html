Перед началом

Откройте урок на компьютере, с которого будете настраивать сервер. На телефоне удобно сверяться с шагами, но устанавливать редактор нужно на компьютере.

  • VPN из подготовительного урока включён; сайты Claude и ChatGPT открываются.
  • Есть доступ к подписке Claude для Claude Code и к подписке ChatGPT для OpenClaw. Это два разных входа.
  • Под рукой почта, приложение для кодов 2FA и способ оплаты сервера из подготовки.
  • Вы можете устанавливать программы на свой компьютер. На рабочем устройстве с ограничениями сначала согласуйте установку с администратором.

Если вход или оплата ещё не работают, вернитесь в подготовку: следующие шаги зависят от этих доступов.

Как распределить время

Первый подход: части 1–4, около 2–3 часов. Подготовьте редактор и инструменты, выполните первую задачу.

Второй: части 5–8, около 1,5–2 часов. Подключите сервер и модель. Ожидание активации VPS в это время не входит.

Третий: части 9–10, около часа. Подключите Telegram, голос и проверьте всё ещё раз.

Это ориентиры для планирования, а не таймер. Если что-то не работает, используйте разбор ошибок.

Видеозаписи на этой странице не размещены. Все действия описаны в тексте; скриншоты можно открыть крупнее.

Редактор и Claude Code

Проверки выполнены

Claude Code отвечает в редакторе, а команда claude доступна в терминале.

  1. Скачайте Visual Studio Code.

    На macOS распакуйте архив и перенесите приложение в «Программы».

    На Windows запустите установщик. Оставьте предложенные настройки и завершите установку.

  2. Создайте папку Vibe Coding в «Документах». Внутри создайте AI-office.
  3. В VS Code выберите File → Open Folder и откройте AI-office. Подтвердите доверие этой своей папке, если редактор спросит.
  4. Откройте Extensions, найдите Claude Code от Anthropic и нажмите Install.
  5. Откройте панель Claude Code. Нажмите Sign in, войдите в браузере в аккаунт с подпиской Claude из подготовки. Вернитесь в редактор и отправьте: «Ответь одним словом: готово».
Где открыть панель Claude Code

Меню команд: Cmd + Shift + P, затем введите Claude Code и выберите Open in New Tab.

Меню команд: Ctrl + Shift + P, затем введите Claude Code и выберите Open in New Tab.

Установите терминальную версию

Расширение включает Claude Code для своей панели. Для команд подключения сервисов нужна ещё отдельная CLI — версия, которая запускается из терминала.

📋 Терминальная версия · в Claude Code
Проверь, установлен ли на моём компьютере терминальный Claude Code: выполни claude --version. Если команда недоступна, сначала определи мою ОС и проверь установку и PATH. Если CLI не установлен, открой https://code.claude.com/docs/en/setup и установи поддерживаемым способом для моей системы. Не запускай скачанный скрипт через pipe: сначала скачай и проверь его. Не меняй уже работающие настройки. Перед правкой существующего конфига сделай копию с датой. Если нужен пароль системы или действие в браузере, остановись и объясни, что мне сделать самому. Пароль не проси в чате. В конце покажи результат claude --version и попроси меня повторить эту команду в новом терминале VS Code.

В VS Code откройте Terminal → New Terminal. Вставьте команду ниже и нажмите Enter. Она должна вывести номер версии.

claude --version

Терминал — окно для текстовых команд. Это отдельная панель редактора, не чат Claude Code. При первом запуске команды claude может потребоваться ещё один вход через браузер: используйте тот же аккаунт.

Не получается войти или команда не найдена

Для входа проверьте VPN и аккаунт с подпиской. Для команды откройте новый терминал после установки. Если ошибка повторяется, отправьте её текст в Claude Code и попросите проверить установку и PATH. Не начинайте повторную установку, пока причина не выяснена.

В графической панели вход выполняется через Sign in. Слэш-команды CLI и кнопки расширения могут отличаться.

Окружение и защита

Проверки выполнены

На компьютере установлен Node.js, DCG проверяет команды перед выполнением.

Оставьте папку AI-office открытой. В ней будут общие инструкции и отдельные подпапки связок. Другие проекты позже можно хранить рядом, в Vibe Coding.

Папка помогает организовать файлы. Само её открытие в редакторе не ограничивает доступ Claude Code ко всему остальному компьютеру.

Установите Node.js

Node.js запускает программы на JavaScript. Он нужен для инструментов и кода связок. Выберите промпт под свою систему.

📋 Node.js · macOS · в Claude Code
Проверь Node.js, npm и Homebrew на моём Mac. Если подходящий Node.js LTS уже установлен, сохрани его. Если нет, помоги установить Homebrew с https://brew.sh и актуальную LTS-версию Node.js по официальной инструкции. Скачанные скрипты сначала сохрани и проверь, не передавай их напрямую в shell. Если нужен пароль системы, дай мне инструкцию для ручного ввода, не проси пароль в чате. Объясняй действия простыми словами. В конце выполни node -v и npm -v. Затем попроси меня открыть новый терминал и повторить обе команды.
📋 Node.js · Windows · в Claude Code
Проверь Node.js и npm на моём компьютере с Windows. Если подходящий Node.js LTS уже установлен, сохрани его. Если нет, помоги установить актуальную LTS-версию с https://nodejs.org/en/download для моей архитектуры. Используй Windows-инструкции, не предполагай наличие bash или WSL. Действия установщика, которые я должен подтвердить, объясняй по одному. В конце выполни node -v и npm -v. Затем попроси меня открыть новый терминал PowerShell и повторить обе команды.
node -v
npm -v

Подключите DCG

DCG проверяет команды до запуска и блокирует известные опасные действия. Прямая правка файлов и некоторые способы выполнения могут выходить за пределы такой проверки. Резервные копии всё равно нужны.

📋 Установка и проверка DCG · в Claude Code
Установи DCG из https://github.com/Dicklesworthstone/destructive_command_guard для моей ОС и подключи его к Claude Code. Прочитай актуальную инструкцию; на Windows выбери поддерживаемый Windows-вариант. Сохрани существующие хуки. Перед правкой настроек сделай копию с датой. Не запускай установку через curl | sh или аналогичный pipe. Проверь версию DCG, его штатную самопроверку и подключение к тому инструменту выполнения команд, который использует моя сессия. Тест опасной команды проводи только через предусмотренный DCG режим проверки, без её реального выполнения и без удаления файлов. Покажи краткий результат: версия, какой хук подключён, какую тестовую команду DCG отклонил. Если хук не подключён, не объявляй защиту готовой.
Проверка DCG должна завершиться до работы с файлами. Если DCG блокирует действие, выясните причину. Не просите Claude Code обходить блокировку.
Резервная копия и дополнительные ограничения

Проверьте, что у важных файлов есть резервная копия, которую вы можете открыть. На macOS это может быть Time Machine; на Windows — резервное копирование выбранных папок.

Отдельные инструкции: ограничение рабочей папки, дополнительная защита macOS, дополнительная защита Windows. Они необязательны для этого маршрута. При жёстком ограничении доступа установку глобальных скиллов и настройку SSH придётся согласовывать отдельно.

Первая задача и правила

Проверки выполнены

Вы задаёте небольшую задачу, проверяете изменение файла и сохраняете правила проекта.

Создайте и измените один файл

📋 Учебный файл · в Claude Code
Помоги составить README.md для папки AI-office. Сначала спроси, чем занимается мой бизнес и какую одну задачу я хочу поручить боту. Из моих ответов составь короткий файл: «Бизнес», «Задача бота», «Как я проверю результат». Не придумывай ответы за меня. Если README.md уже существует, сначала покажи, что предлагаешь добавить, и дождись подтверждения. После сохранения покажи путь к файлу.
  1. Ответьте на вопросы Claude Code. Откройте README.md в списке файлов слева и прочитайте его.
  2. В чате наберите @ и выберите README.md. Попросите заменить задачу бота на другую вашу задачу.
  3. Посмотрите предлагаемые изменения. Подтвердите их, затем снова откройте файл и проверьте изменённую строку.
  4. Найдите историю сессий. Откройте новый разговор и вернитесь к предыдущему через историю.
Как выглядит проверка изменения

Запишите правила в CLAUDE.md

CLAUDE.md в корне проекта содержит инструкции для следующих сессий. Это текстовые правила, а не техническая блокировка действий.

📋 Правила проекта · в Claude Code
Собери CLAUDE.md для проекта AI-office. Сначала прочитай README.md. Спроси по одному вопросу о том, как со мной общаться и какие папки проекта не трогать. Не выдумывай структуру папок. Добавь правила: - По-русски, коротко. Новые термины объяснять одной строкой. - Перед изменением существующих файлов показать план. Перед правкой конфига сохранить копию с датой. - Не удалять файлы, не публиковать данные и не менять доступы без моего явного подтверждения. - Реальные ключи и пароли я ввожу сам в указанное поле или локальный файл. Не просить их в чате, не читать и не показывать их значения. - Файлы с секретами сначала исключать из Git. Не добавлять их в коммиты и скриншоты. - Настройку .env и других конфигов выполнять только для согласованной задачи. Не менять посторонние ключи. - При блокировке DCG объяснить причину и выбрать безопасное действие, не обходить защиту. - Для OpenClaw обращаться к установленному скиллу openclaw-docs и проверять результат команды. Сохрани файл в корне проекта. Покажи текст правил без секретов.

В панели Claude Code наберите /, чтобы открыть меню. В расширении часть действий доступна кнопками, а некоторые команды открываются в терминале.

Режимы разрешений и Bypass Permissions

Для первой практики используйте режим с подтверждением изменений: в актуальном расширении это Manual. Plan позволяет сначала обсудить план без правки файлов.

Bypass Permissions отключает обычные запросы разрешения. DCG при этом не превращается в полную защиту компьютера. Этот режим не нужен для прохождения урока; включайте его только если понимаете доступы и готовы к самостоятельным действиям агента.

Надписи и доступные режимы зависят от версии. Если указанной команды нет, найдите действие через меню / или справку расширения.

Перед завершением большой задачи попросите сохранить в README, что уже работает и на чём остановились. Так следующая сессия сможет продолжить по файлу.

GitHub, браузер и скиллы

Проверки выполнены

Claude Code читает учебный репозиторий, открывает сайт через Playwright и находит установленные скиллы.

Подготовьте GitHub и токен

На GitHub хранится код связок. MCP подключает внешние инструменты к Claude Code. Подключим GitHub и браузер Playwright.

  1. Зарегистрируйтесь на GitHub и подтвердите почту.
  2. Откройте Settings → Password and authentication → Two-factor authentication. Включите 2FA через приложение-аутентификатор. Сохраните резервные коды в менеджере паролей.
  3. На GitHub нажмите New repository, назовите его ai-office и выберите Private. Это отдельное место для вашего кода; загружать туда ключи нельзя.
  4. Откройте создание Fine-grained personal access token. Название — Claude Code, срок — 90 дней, владелец — ваш аккаунт. В Repository access → Only select repositories выберите только ai-office.
  5. В Repository permissions задайте Contents: Read and write, Issues: Read and write и Pull requests: Read and write. Чтение Metadata добавится автоматически. Остальные права не добавляйте. Создайте токен и сохраните его в менеджере паролей.

Contents нужен для файлов, Issues — для задач, Pull requests — для предложений изменений. Для чтения открытых учебных репозиториев отдельные права на них не требуются. Новые разрешения добавляйте тогда, когда конкретная связка их попросит. Справка GitHub о токенах.

Подключите GitHub без передачи токена в чат

Сначала Claude Code подготовит файл настройки с заглушкой. Затем вы сами вставите токен в редакторе. Не прикрепляйте этот файл через @ и не отправляйте его в поддержку.

📋 Настройка GitHub MCP · в Claude Code
Подключи официальный удалённый GitHub MCP к этому проекту Claude Code. Сначала прочитай https://code.claude.com/docs/en/mcp и https://github.com/github/github-mcp-server/blob/main/docs/installation-guides/install-claude.md. Токен я введу сам. Не спрашивай и не читай его значение. 1. Проверь, нет ли уже подключения GitHub. Если оно работает, сохрани его и переходи к проверке чтения репозитория. 2. Если подключения нет, сначала добавь .mcp.json, .env и .secrets/ в .gitignore. Не затирай существующие правила. Объясни, что это исключение из Git, а не ограничение доступа к файлам. 3. Создай .mcp.json в корне AI-office. Сохрани другие MCP, если они есть; перед изменением существующего файла сделай копию с датой и исключи копию из Git. Для github используй type http, URL https://api.githubcopilot.com/mcp/ и заголовок Authorization со значением Bearer PASTE_GITHUB_PAT_HERE. 4. Попроси меня открыть .mcp.json в редакторе, заменить только PASTE_GITHUB_PAT_HERE на токен, сохранить файл и перезапустить сессию. После этого не читай и не выводи этот конфиг. 5. Попроси меня разрешить подключение MCP проекта, открыть /mcp и проверить github. Проверяй ошибки без вывода заголовков авторизации.

Рабочий сервер

Проверки выполнены

У вас есть активный VPS и доступ к нему. На нём будут работать OpenClaw и серверные связки.

VPS — компьютер, который вы арендуете у хостинга. Он остаётся включённым, когда ваш ноутбук закрыт. Для шести серверных связок курса рекомендуем конфигурацию с запасом:

ПараметрРекомендация для курса
Процессор4 vCPU, архитектура x86-64
Память8 ГБ RAM
ДискОт 120 ГБ SSD/NVMe: код, контейнеры, данные и журналы
Система нового VPSUbuntu 24.04
ЛокацияСША или страна Европы, где доступны нужные сервисы

Это рекомендация для общей нагрузки курса, а не универсальный минимум OpenClaw. Потребление ресурсов зависит от связок и объёма данных. Связка с Suvvy проходит на отдельной платформе.

Если подходящий сервер уже есть

Откройте его параметры в кабинете хостинга. Сервер с VPN можно использовать, если ресурсов хватает и есть доступ для настройки. На шаге подключения скажите Claude Code, что VPN уже работает.

На сервере с VPN или другими данными не переустанавливайте систему и не нажимайте Reinstall. Сначала сохраните резервную копию средствами хостинга и проверьте её наличие. Установку OpenClaw согласуйте так, чтобы существующие сервисы продолжили работать.

Если сервер нужно купить

  1. Откройте тарифы netcup VPS. Под параметры выше подходит VPS 1000 G12: 4 vCore, 8 ГБ RAM, 256 ГБ NVMe.
  2. Выберите локацию и срок оплаты. Проверьте итоговую стоимость, налоги, автопродление и условия отмены до оплаты.
  3. При создании нового сервера выберите Ubuntu 24.04. Не выбирайте платный образ с заранее установленными приложениями, если он не нужен.
  4. Оплатите способом из подготовки. Хостинг может запросить подтверждение данных; срок активации зависит от проверки.
  5. После активации сохраните IP-адрес, имя пользователя и первоначальный пароль в менеджере паролей. Найдите в кабинете хостинга удалённую консоль: она пригодится для восстановления доступа.

На витрине netcup 10.09.2026 VPS 1000 G12 указан от €10,37 в месяц с НДС 19%. Цена для вашего заказа может отличаться. Источник: страница тарифа.

Если netcup не подходит

Можно выбрать Hetzner, DigitalOcean, Vultr или Linode. Сравнивайте конфигурацию и полную стоимость, а не самый дешёвый тариф на главной странице.

География и репутация конкретного IP могут влиять на доступ к сервисам. Название компании не заменяет проверку соединения. Проверим доступ с сервера при подключении модели; не оплачивайте большой срок только ради прохождения урока.

Подключение по SSH

Проверки выполнены

Команда ssh my-server подключает вас к серверу по ключу. Парольный вход отключён только после проверки.

SSH создаёт защищённое соединение с сервером. У ключа две части: приватная остаётся на компьютере, публичная добавляется на сервер. Приватную часть никому не отправляйте. Парольная фраза ключа, если вы её зададите, отличается от пароля сервера.

Откройте новую сессию Claude Code в AI-office. Отправьте промпт. IP и имя пользователя можно сообщить в чате; пароль вводите только в терминале, когда он его запросит.

📋 Вход по SSH-ключу · в Claude Code
Помоги подключить мой компьютер к VPS по SSH-ключу. Сначала спроси IP сервера, SSH-порт, имя пользователя и есть ли на нём VPN или другие работающие сервисы. Пароль сервера и приватный ключ в чате не запрашивай. Определи ОС и оболочку моего компьютера. Проверь существующие ключи и SSH-настройки без чтения содержимого приватных ключей. Не перезаписывай ключи, не меняй уже работающие алиасы; перед изменением конфигов сделай копии с датой. 1. Если подходящего ключа нет, помоги создать отдельный ed25519. Объясни парольную фразу и ssh-agent; предложи вариант, при котором ключ не требует ввода при каждом соединении. 2. Проведи меня через первый ручной вход. Сверь отпечаток SSH-хоста с консолью хостинга; не отключай проверку хоста. Пароль я введу сам. 3. Добавь публичный ключ на сервер способом для моей ОС. На macOS ssh-copy-id используй только если он установлен. На Windows не предполагай наличие ssh-copy-id: используй поддерживаемый способ через OpenSSH. Сохрани существующие authorized_keys и права доступа. 4. Добавь алиас my-server в SSH-конфиг компьютера: правильные HostName, User, Port и IdentityFile. Если my-server занят другим сервером, остановись и предложи другой алиас; затем используй выбранный во всех шагах. 5. Попроси меня открыть второй терминал и проверить ssh my-server. Первое соединение оставь открытым. Проверь также соединение из своей сессии. 6. Только после успешной проверки предложи отключить парольную аутентификацию. Учти активные sshd_config.d и keyboard-interactive, проверь итоговые параметры и синтаксис до применения. Дождись моего подтверждения, примени без потери текущего соединения и снова проверь вход по ключу в новом терминале. После каждого этапа объясняй, что я должен увидеть. При ошибке остановись на ней, не переходи дальше. Систему, VPN, порты других сервисов и файрвол без отдельного согласования не меняй.
Перед отключением пароля держите первое соединение открытым. Если новое соединение не получилось, не закрывайте рабочее окно и не продолжайте отключение доступа.

Если выбрали другой алиас: заменяйте my-server на своё короткое имя во всех командах и промптах ниже. Перед настройкой всегда проверяйте через hostname, что вошли на нужный сервер.

Проверьте вход сами

Терминал вашего компьютера
ssh my-server

После входа командная строка показывает пользователя и имя сервера. Для проверки выполните:

hostname

Теперь команды выполняются на сервере. Чтобы вернуться на компьютер, наберите exit. Для следующего шага оставьте проверенное подключение доступным.

Алиас не найден или сервер просит пароль

Could not resolve hostname my-server: SSH не нашёл алиас. Попросите Claude Code проверить конфиг именно той системы, из которой вы подключаетесь. У Windows и WSL могут быть разные домашние папки и ключи.

Enter passphrase for key: это парольная фраза локального ключа. Введите её сами или настройте ssh-agent с помощью Claude Code.

Permission denied (publickey): проверьте пользователя, выбранный ключ и его публичную часть на сервере. После отключения парольного входа root-пароль не станет запасным способом. Используйте оставленное соединение или консоль хостинга.

openclaw onboard --install-daemon

Этот вариант открывает полный мастер и включает установку фоновой службы. Служба нужна, чтобы OpenClaw продолжал работать после закрытия терминала. Мастер проходите руками: стрелки для выбора, Enter для подтверждения.

  1. Прочитайте предупреждение о доступах. Для установки на текущем VPS выбирайте локальную настройку Gateway. Не выбирайте сброс или удаление существующей конфигурации.
  2. В выборе провайдера найдите OpenAI и вход через аккаунт ChatGPT/Codex. Используйте подписку из подготовки. Ввод API key относится к отдельной оплате API.
  3. Откройте ссылку авторизации на своём компьютере, войдите в нужный аккаунт и вернитесь в мастер. Если он просит код или полный адрес возврата, вставьте его только в терминал мастера, не в чат Claude Code.
  4. Выберите доступную модель и выполните пробный запрос, когда мастер его предложит. Если ответ не пришёл, исправьте авторизацию или доступ к модели до продолжения.
  5. Завершите остальные шаги: Gateway только на loopback, порт 18789, доступ с токеном. Telegram, дополнительные скиллы и веб-поиск сейчас можно пропустить. Дойдите до установки службы и проверки её работы.

Как расходуется подписка

Лимит зависит от модели, объёма задачи, контекста и настроек. OpenAI описывает окна использования, в том числе пятичасовые; могут действовать и недельные ограничения. Это не означает «пять часов работы в неделю».

Остаток и время сброса проверяйте в разделе использования аккаунта. В OpenClaw сведения об авторизации и доступные данные о квоте можно посмотреть командой openclaw models status.

low — первая проверка и короткие задачи. medium — промежуточный вариант. high — когда задаче нужна более глубокая проработка. Поддержка xhigh и max зависит от модели; не назначайте их всем запросам подряд.

При исчерпании квоты дождитесь сброса или выберите доступный более экономный вариант. Покупка кредитов и работа через API оплачиваются отдельно. Условия OpenAI.

Откройте панель через SSH-туннель

Туннель связывает локальный адрес в браузере с панелью на сервере. Откройте второй терминал на своём компьютере, без предварительного входа через SSH:

Терминал компьютера · macOS или PowerShell
ssh -N -o ExitOnForwardFailure=yes -L 18789:127.0.0.1:18789 my-server

Если ошибок нет, терминал останется занят без новой командной строки. Оставьте окно открытым. Закроете его — соединение панели с сервером закроется, но служба и Telegram-бот продолжат работать.

В первом терминале, где вы уже на сервере, получите ссылку на панель:

Терминал сервера
openclaw dashboard --no-open

Откройте показанную ссылку с локальным адресом в браузере своего компьютера. Если ссылка содержит токен, сохраните её в менеджере паролей и не отправляйте в чат. Задайте в панели вопрос: «Ответь одним словом: готово».

Порт занят или панель не открывается

Если терминал туннеля сообщает Address already in use, другой процесс использует локальный порт. Не останавливайте его наугад. Используйте свободный локальный порт:

ssh -N -o ExitOnForwardFailure=yes -L 18790:127.0.0.1:18789 my-server

В ссылке панели замените только локальный порт 18789 на 18790, сохранив остальную часть. Если занят и он, попросите Claude Code найти свободный порт.

Если окно туннеля открыто, но панель недоступна, проверьте openclaw gateway status на сервере. Причиной может быть служба, адрес или авторизация, а не только туннель. Не открывайте порт Gateway всему интернету ради проверки.

Telegram и голос

Проверки выполнены

Ваш бот отвечает в Telegram. На голосовое приходят расшифровка и ответ.

Создайте бота

  1. Откройте @BotFather в Telegram. Проверьте точное имя и отметку подлинности.
  2. Отправьте /newbot, укажите название и свободный username, который заканчивается на bot.
  3. Сохраните полученный токен в менеджере паролей. Он даёт доступ к Telegram-боту; не отправляйте его в чат курса или Claude Code.

Это бот для OpenClaw. Для отдельных связок создаются свои боты по их инструкциям. Один и тот же токен не нужно раздавать разным программам.

Введите токен на сервере

Откройте терминал компьютера и выполните ssh my-server, подставив свой алиас, если он отличается. Проверьте имя сервера командой hostname. Команды ниже вводятся на сервере, по очереди. Токен вводится скрыто.

  1. Запустите скрытый ввод:
    read -rsp 'Токен Telegram: ' TELEGRAM_SETUP_TOKEN

    Вставьте токен и нажмите Enter. Символы при вводе не отображаются — это нормально. Не вставляйте следующую команду вместо токена.

  2. Добавьте Telegram:
    openclaw channels add --channel telegram --token "$TELEGRAM_SETUP_TOKEN"

    Команда сохранит токен в настройках OpenClaw. Не закрывайте текущий терминал между первым и вторым действием: переменная существует только в нём.

  3. Очистите временную переменную:
    unset TELEGRAM_SETUP_TOKEN

Эти команды рассчитаны на Bash на Ubuntu-сервере. Их не нужно запускать в локальном PowerShell. Если бот уже подключён и отвечает, не добавляйте его повторно.

📋 Настройки доступа Telegram · в Claude Code
На сервере my-server я вручную добавил Telegram-бота через openclaw channels add. Токен не запрашивай, не читай и не показывай. По скиллу openclaw-docs проверь настройки канала. Для личных сообщений установи dmPolicy pairing, если он ещё не установлен. Не открывай доступ всем пользователям и не включай групповые чаты. Подтвердите доступ своего аккаунта

  1. Откройте своего бота, нажмите Start и отправьте любое короткое сообщение. Для ещё не привязанного аккаунта бот покажет запрос на доступ.
  2. В панели OpenClaw откройте Settings → Channels → DM access requests. Найдите запрос своего Telegram-аккаунта и проверьте отправителя.
  3. Нажмите Approve. Для личного бота включите опцию назначения первого владельца команд, если панель её предлагает. Разрешение переписки и права владельца — отдельные настройки.
  4. Снова напишите боту: «Ответь одним словом: готово». Должен прийти ответ.
Запроса нет или нужен способ через терминал

Сначала проверьте, что Telegram подключён и вы действительно отправили боту сообщение. Запрос появляется после сообщения. Если код истёк, отправьте новое сообщение.

На сервере выполните openclaw pairing list telegram. Затем попросите Claude Code подтвердить именно ваш запрос по инструкции привязки: openclaw pairing approve telegram <CODE>. Вместо <CODE> используется код из вашего запроса. Не подтверждайте неизвестных отправителей.

Если панель одобрила переписку, но команды владельца недоступны, попросите Claude Code проверить владельца команд отдельно. Само разрешение писать боту не всегда назначает администратора.

Подключите распознавание голоса

Создайте аккаунт в Groq Console. В разделе API Keys → Create API Key выпустите ключ и сохраните его. У бесплатного уровня есть ограничения; актуальный остаток проверяется в кабинете Groq.

Отправьте промпт ниже. Claude Code подготовит способ скрытого ввода ключа в терминале сервера. Ключ не нужно пересылать в чат или добавлять в README.

📋 Распознавание и расшифровка · в Claude Code
Подключись к серверу my-server и настрой распознавание голосовых OpenClaw через Groq. Используй скилл openclaw-docs, особенно раздел https://docs.openclaw.ai/nodes/audio. 1. Не спрашивай ключ в чате. Подготовь поддерживаемый способ безопасного хранения GROQ_API_KEY для службы Gateway и команду скрытого ручного ввода в терминале сервера. Ключ я введу сам; команда не должна выводить его, включать его значение в историю или передавать в контекст модели. Не затирай существующие переменные окружения. Перед изменением конфигов сохрани копию с датой. 2. Дождись моего подтверждения, что ключ введён. Проверь доступность ключа службе без чтения и вывода значения. Он должен сохраняться после перезапуска службы, не только в текущем shell. 3. Включи tools.media.audio.enabled. Для аудио используй провайдера groq и модель whisper-large-v3; платные резервные провайдеры не добавляй. Включи tools.media.audio.echoTranscript, чтобы расшифровка отправлялась в чат отдельным сообщением. 4. Проверь конфигурацию, перезапусти Gateway и проверь состояние без вывода секретов. 5. Попроси меня отправить голосовое «Повтори число 27». После моего теста проверь обработку аудио и объясни ошибки, если они есть. Не объявляй голос готовым до реального сообщения.

Запишите боту голосовое: «Повтори число 27». Ожидаются расшифровка с числом 27 и ответ бота с этим числом. Написание «27» и «двадцать семь» одинаково подходит.

Голос не распознаётся или нет отдельной расшифровки

Если текст работает, а голос нет, проверьте обработку аудио, доступность ключа службе и лимит Groq. Если бот понял голос, но не прислал расшифровку, проверьте echoTranscript.

Если качество плохое, повторите короткое голосовое без фонового шума. Сначала разберите конкретную ошибку. Платное распознавание OpenAI можно подключить позже отдельным решением; оно использует API-ключ и отдельный баланс, а не подписку ChatGPT.
